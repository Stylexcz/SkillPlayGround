# Minino Wiki

This wiki documents the Minino board, an original multiprotocol and multiband board designed for sniffing, communicating with, and attacking IoT devices.

The entry point is [Understanding Minino](understanding-minino.md). It gives a high-level overview of the product and guides you to the specialized pages.
